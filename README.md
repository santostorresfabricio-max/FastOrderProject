# FastOrder — Trabajo Final de Aplicaciones Web Progresivas

Proyecto Angular 19 responsive con carrito, pedidos, cocina, modo offline, instalación PWA y notificaciones.

Consulta **GUIA_ENTREGA_FINAL.md** para instrucciones completas y el estado de cada requisito.

## Arranque local

```bash
npm install
npm run server  # terminal 1
npm start       # terminal 2
```

## PWA en producción

```bash
npm run build
npm run serve:production
```

Abrir http://localhost:8080. En despliegue público, utilizar HTTPS y controles de acceso.
