# FastOrder UI · Fase Web Responsive

- **Estilo**: restaurante contemporáneo / identidad cálida y editorial.
- **Colores**: rojo acción `#e94b31`, verde oscuro `#24352b`, crema `#fbf9f4`, tinta `#1c201e`, gris `#777973`.
- **Fuentes**: Outfit para títulos, DM Sans para textos; fallbacks sans-serif.
- **Contenedores**: máximo de 1180 px; márgenes laterales fluidos.
- **Desktop**: navegación horizontal, hero en dos columnas, catálogo lateral + rejilla, checkout en dos columnas.
- **Tablet (<1050 px)**: grids de 2 columnas, categorías de 2 columnas.
- **Móvil (<750 px)**: navegación desplegable, hero vertical, filtros desplazables, formularios y checkout de una columna.
- **Accesibilidad**: controles nativos donde sea posible, estados definidos por texto y color, enlaces con destinos reales.
- **Futuras fases**: reemplazo de datos mock por API, componentes reales de formularios, acciones de carrito, autenticación, PWA, estado offline, sincronización y Web Push.
